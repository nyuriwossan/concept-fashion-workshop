# コンセプトファッション工房

感情・神話・自然・民族衣装・美術様式などのモチーフを、画像生成AI向けの衣装プロンプトへ変換するスマホ優先のWebアプリです。

公開ページ: https://nyuriwossan.github.io/concept-fashion-workshop/

## MVPの主な機能

- 10カテゴリ・50モチーフの衣装化データ
- テイスト、衣装ベース、反映先、反映強度、構造、見せ場の設計
- 民族・伝統衣装用の地域、衣装、アレンジ設定
- 文化的文脈に配慮した露出度スライダー
- 衣装を主役にする12種類の見せ方プリセット
- `衣装だけ` / `衣装＋ポーズだけ` / `全部` の出力範囲切替
- 英語の完成版・短め版、日本語要約、分解表示、コピー
- 任意の画風・仕上げ指定

## 開発

```sh
npm install
npm run dev
```

生成ロジックのテストと完成ページの検査は `npm test` で実行します。
